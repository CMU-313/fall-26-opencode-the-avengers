## Generators

All properties share one content generator. It mixes three sources: arbitrary strings from `fc.string()`, fixed markdown fragments (a heading, a list item, a fenced code block, the empty string, a blank line), and random concatenations of those fragments. Arbitrary strings catch general byte-handling problems. The fragments and their concatenations cover the cases the interviews cared about: markdown structure (S-1, C-5), empty content, and content that ends without a newline. R3 draws two contents so the original and replacement can differ, and R1 also draws a boolean for whether the file already exists.
