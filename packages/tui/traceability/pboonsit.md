## Requirement changes

| ID  | Original (P3)                                                                                                                                     | Revised (P4)                                                                                                                                             | Reason                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R4  | If `/save` is triggered while the agent is still generating, it must wait until generation completes before saving, never saving partial content. | The save command operates on the completed assistant response: it saves the full response text and never a partially generated one.                      | Conflict + checkability. The interview evidence conflicts (C-5 wanted partial content with a cut-off marker; S-5 and O-5 wanted the whole response). As originally stated it also isn't checkable against the save function, which has no notion of generation state. The revision keeps the majority expectation (save the complete response). |
| R1  | The save command should allow appending a response to an existing file without overwriting it.                                                    | Dropped from the tested set for this project; not implemented in `writeResponseFile`, which overwrites or declines. Kept as a candidate for future work. | Scope. Append is feasible but is new feature work beyond this project's testing focus; R5 and R6 give fuller coverage of the current save behavior.                                                                                                                                                                                             |
